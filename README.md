## Projekt inżynierski ##

## Temat ##
System sterowania manipulatorem ramienia robota z wykorzystaniem systemu wizyjnego.

## Struktura projektu ##
    -desktop-app: Aplikacja desktopowa odpowiedzialna za akwizycję obrazu z kamery lokalnej oraz jego analizę i przetwarzanie
    -web-cam: Aplikacja webowa odpowiedzialna za akwizycję obrazy z kamery zdalnej
    -websocket: Serwer umożliwiający komunikację pomiędzy modułami aplikacji
